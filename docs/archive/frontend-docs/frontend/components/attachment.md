# Attachment

File chip in the conversation layer. Uses **`state`** for lifecycle, not `variant`.

## States

`idle`, `uploading`, `processing`, `error`, `done`

## Media type

`AttachmentMedia` uses **`type`**: `icon` | `image`

## Tokens

- `size-attachment-media` (+ sm/xs) - media dimensions
- `shadow-destructive-ring` - error border
